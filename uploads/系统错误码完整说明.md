# 系统错误码完整说明

## 一、错误码体系设计

所有系统错误码遵循以下格式：

```
E-{模块代码}-{错误序号}
```

模块代码对照：

| 模块代码 | 模块名称 |
|---------|---------|
| USR | 用户服务 |
| ORD | 订单服务 |
| PAY | 支付服务 |
| PRD | 商品服务 |
| MSG | 消息服务 |
| AUTH | 认证服务 |
| SYS | 系统级错误 |

## 二、用户服务错误码（E-USR-xxxx）

| 错误码 | 错误消息 | 触发条件 | 建议操作 |
|-------|---------|---------|---------|
| E-USR-1001 | 手机号已被注册 | 注册时手机号已存在 | 引导用户直接登录或找回密码 |
| E-USR-1002 | 邮箱格式不正确 | 输入的邮箱不符合规范 | 前端校验 + 提示正确格式 |
| E-USR-1003 | 验证码已过期 | 验证码超过 5 分钟有效期 | 引导用户重新获取验证码 |
| E-USR-1004 | 验证码错误 | 输入验证码与发送的不一致 | 提示剩余尝试次数（最多 5 次） |
| E-USR-1005 | 账号已被冻结 | 违规操作导致账号冻结 | 引导至申诉页面 |
| E-USR-1006 | 昵称包含敏感词 | 用户输入昵称命中敏感词库 | 提示修改昵称 |
| E-USR-1007 | 登录密码错误 | 密码与账号不匹配 | 提示剩余尝试次数，连续错误 5 次锁定 15 分钟 |
| E-USR-1008 | Token 已过期 | JWT Token 超过有效期 | 前端自动刷新 Token 或引导重新登录 |

## 三、订单服务错误码（E-ORD-xxxx）

| 错误码 | 错误消息 | 触发条件 |
|-------|---------|---------|
| E-ORD-2001 | 商品库存不足 | 下单时库存为 0 或小于购买数量 |
| E-ORD-2002 | 订单不存在 | 查询的 order_id 在系统中不存在 |
| E-ORD-2003 | 订单状态不允许此操作 | 订单状态流转违反状态机规则（如对已退款订单再次退款） |
| E-ORD-2004 | 重复订单 | 同一用户 5 分钟内提交完全相同的订单 |
| E-ORD-2005 | 订单已过期 | 待支付订单超过 30 分钟未支付自动取消 |

## 四、支付服务错误码（E-PAY-xxxx）

| 错误码 | 错误消息 | 触发条件 |
|-------|---------|---------|
| E-PAY-3001 | 支付金额与订单不一致 | 支付金额与订单金额偏差超过 0.01 元 |
| E-PAY-3002 | 支付渠道异常 | 微信/支付宝渠道返回错误 |
| E-PAY-3003 | 重复支付 | 同一订单号在 30 秒内收到两次支付通知 |
| E-PAY-3004 | 退款金额超过订单金额 | 部分退款累计金额超过订单总额 |
| E-PAY-3005 | 用户余额不足 | 钱包支付时余额小于订单金额 |

## 五、系统级错误码（E-SYS-xxxx）

| 错误码 | 错误消息 | 说明 |
|-------|---------|------|
| E-SYS-5000 | 系统繁忙，请稍后重试 | 通用系统异常，建议指数退避重试 |
| E-SYS-5001 | 数据库连接超时 | 数据库连接池耗尽或网络抖动 |
| E-SYS-5002 | 缓存服务异常 | Redis 集群不可用，已降级走数据库 |
| E-SYS-5003 | 消息队列发送失败 | Kafka 发送异常，已写入本地重试表 |
| E-SYS-5004 | 第三方服务超时 | 调用外部 API 超过 10 秒未响应 |
| E-SYS-5005 | 文件上传大小超限 | 上传文件超过 10MB 限制 |

## 六、客户端错误处理建议

1. **400 系列错误**：读取响应体中的 `message` 字段，直接展示给用户
2. **E-AUTH 系列错误**：引导用户重新登录，不要重试
3. **E-SYS 系列错误**：采用指数退避策略重试（首次 1s、二次 3s、三次 9s，最多 3 次）
4. **E-PAY-3001/3003/3004**：不要重试，直接展示错误信息并要求用户联系客服，避免重复扣款
5. 所有错误响应体格式为 `{"code": "E-ORD-2001", "message": "商品库存不足", "details": {...}}`
